# TypeScript Projects

> Making JavaScript more predictable, scalable, and maintainable through static typing. TypeScript projects and practical implementations.

Welcome to my TypeScript workspace. This repository contains projects built using **plain TypeScript**, exploring its type system, language features, and practical applications.

The mission is to write predictable, maintainable, and type-safe code while developing a deeper understanding of TypeScript beyond basic type annotations.

## What's Inside?

| Directory | Description |
|---|---|
| `projects/` | Practical projects, utilities, and implementations built using TypeScript |

## Areas of Focus

- TypeScript Fundamentals
- Type Annotations and Type Inference
- Interfaces and Type Aliases
- Union and Intersection Types
- Functions and Function Types
- Classes and Object-Oriented Programming
- Generics
- Enums and Literal Types
- Type Guards and Narrowing
- Utility Types
- Advanced Types
- Modules and Code Organization
- Error Handling
- Strict Type Checking

## Technologies

- TypeScript
- JavaScript
- Node.js (where required)

## Philosophy

Types are not decorations. They are part of the engineering process.

The objective is to understand TypeScript beyond adding type annotations and to use its type system to build more reliable, predictable, and maintainable software.

**Built with TypeScript, strict mode, and a healthy distrust of `any`.**
